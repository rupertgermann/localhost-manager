# Lokale Server

**Projekt**  
Eine Gruppe von Diensten, die zu derselben Entwicklungsumgebung gehören.

**Dienst**  
Ein einzeln bedienbarer Teil eines Projekts, etwa das Frontend, die API oder eine Datenbank. Ein Dienst kann mehrere Ports haben. Ein gespeicherter Dienst bleibt auch im gestoppten Zustand sichtbar.
