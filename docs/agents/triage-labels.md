# Triage-Labels

| Status | Bedeutung |
| --- | --- |
| `needs-triage` | Das Ticket wartet auf Einordnung. |
| `needs-info` | Für die Einordnung fehlen Angaben der meldenden Person. |
| `ready-for-agent` | Ein Agent kann das Ticket eigenständig umsetzen. |
| `ready-for-human` | Die Umsetzung erfordert einen Menschen. |
| `wontfix` | Das Ticket wird nicht umgesetzt. |
