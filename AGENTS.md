## Releases

Baue und verpacke die macOS-App ausschließlich lokal auf einem Mac. Veröffentliche bei einem Release-Auftrag das geprüfte ZIP samt SHA-256-Prüfsumme als GitHub Release in `rupertgermann/localhost-manager`. Lade das veröffentlichte ZIP ohne Anmeldung herunter und verifiziere die Prüfsumme.

Lies für Build, Paketprüfung und Veröffentlichung den [Release-Leitfaden](docs/releasing.md).
